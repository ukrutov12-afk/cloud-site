# Zephyr — дизайн по визуальным референсам, версия 3

Новая композиция по шести предоставленным скриншотам. Заимствованы общие принципы
оформления, а тексты, изображения, логотип и функциональность относятся к Zephyr.

## Оформление

- Узкая плавающая шапка с мягкими скруглениями.
- Почти чёрный фон с редкими статичными точками в первом экране.
- Компактные заголовки по центру и отдельные фиолетовые акценты.
- Реальный скриншот Zephyr с плавным затуханием на первом экране.
- Две колонки возможностей HUD и профилей, небольшие иллюстративные элементы.
- Широкий блок лаунчера и два визуальных блока модулей/HUD.
- Галерея клиента с кнопками, клавиатурой и свайпами.
- Разделы запуска, тарифов, FAQ и поддержки в общей системе оформления.
- Фиолетовый заключительный баннер и компактный подвал.
- Светлая секция и огромные заголовки предыдущего варианта удалены.

Иллюстрации модулей и HUD созданы средствами HTML/CSS из исходных SVG-иконок;
они не являются новыми функциями клиента. Чужие скриншоты, логотипы и тексты
на сайт не добавлены. Функции Globals, рефералы и маркет из референса не заявлены.
Тексты добавлены для ru/en/uk/be. Шрифт Onest поставляется локально с лицензией OFL.

## Перенос на сайт

Перенесите **public**, **views** и **locales** в корень репозитория с заменой файлов.
Все три папки обязательны. Не загружайте ZIP или внешнюю папку cloud-site-main
вместо содержимого. Сервер, база и переменные окружения остаются прежними.
Перезапустите приложение или выполните деплой на существующем хостинге.

```sh
npm ci
npm start
```

## Проверка

- Главная, покупка, вход, регистрация, поддержка, документация и 404 проверены
  в Chromium на 320, 390, 768 и 1440 px. Горизонтального переполнения нет.
- Проверены вход, кабинет, админка, страница 2FA и покупка после авторизации.
- Галерея, FAQ, переключение темы, мобильное меню и Escape работают.
- Главная проверена на четырёх языках с локально загруженным шрифтом.
- Ошибок JavaScript в проверенных сценариях нет.
- Серверные файлы и исходные изображения сверены с оригинальным архивом.

Реальные платежи, production PostgreSQL, нативный мост лаунчера и полный аудит
WCAG не проверялись. Новые тестовые пользователи, сессии и node_modules не включены.
На действующий сайт и в GitHub изменения автоматически не отправлялись.
